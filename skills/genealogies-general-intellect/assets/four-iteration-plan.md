# Four-Iteration Plan — Genealogies of the General Intellect

Source of truth: `/root/.openclaw/genealogies-general-intellect/backlog/roadmap.md`. This file mirrors and operationalises it. Update only with Marcus's consent.

## Iteration 1 — Fundament

- Pilot decision (Bremen + Berlin 1960–2026).
- Source/claim schemas review.
- Seed source search.
- Validator stabilisation.

## Iteration 2 — Ein begrenzter Medienfall (current pilot frame)

- One week or one month, one place, ≥3 source types.
- Separate availability / rotation / reception.
- Active sub-tasks: **WP-05/WP-06 Bremen/Berlin August 1961**
  (DRA Berlin, ZEFYS, Radio Bremen, RIAS, SFB; local press).
- Acceptance: at least one resilient source chain per city OR documented gap;
  no fabricated playlists/schedules/ratings; all records carry
  id+source+status+uncertainty+provenance.

## Iteration 3 — Vergleich und Vermittlung

- Add a contrasting group or region.
- Make source gaps + different media accesses visible.

## Iteration 4 — Kuratierung und Wirkung

- Test a short literature or media path with real human use.
- Run life-impact evaluation.

## Operational Notes

- Every iteration produces: updated `backlog/now.md`, `AGENT_CHANGELOG.md`
  entry, at least one validator pass.
- Iteration 2 explicitly pilots the skill; iterations 3 + 4 must not be
  initiated before iteration 2 acceptance.
- The Nurse with Wound List stays a curatorial document across all four
  iterations; it is **not** an automatic canon.
