## 2026-07-26 Abend — Deploy-Fiasko & Fix (working-notes.org)

### Symptom
- User meldete "Ich sehe darin immer noch Leute Marcus" auf 004-group-collage.
- Lokal war alles korrekt gebaut. Live war trotzdem alter Stand.
- rsync-Deploy scheiterte 4× aus verschiedenen Gründen.

### Root Cause #1: Credentials am falschen Ort
- `/root/.env` ist leer (nur Platzhalter für LLM-Keys).
- `/root/.hermes/.env` hat keine IONOS-Vars.
- **Echte Credentials:** `/root/.openclaw/workspace/projects/working-notes/.env` (mode 600, vom `credential-manager` Skill dorthin migriert).
- Inhalt: `IONOS_USER=su641339`, `IONOS_HOST=access-5019640593.webspace-host.com`, `IONOS_PASSWORD=(rQBJ}…2206`.

### Root Cause #2: Bash `source` bricht bei `(` im Passwort
- `set -a && source .env && …` wirft `unexpected EOF while looking for matching ')'`.
- **Fix:** `.env` mit **Python** parsen, nicht bash.
  ```python
  env = {}
  with open('/root/.openclaw/workspace/projects/working-notes/.env') as f:
      for line in f:
          line = line.strip()
          if line and not line.startswith('#') and '=' in line:
              k, v = line.split('=', 1)
              env[k] = v
  os.environ['SSHPASS'] = env['IONOS_PASSWORD']
  ```

### Root Cause #3: Directory-Permissions nach rsync zu restriktiv
- Lokale `_site/`-Files hatten mode 600 (weil von Roo/Kreator gebaut).
- `rsync -avz --delete` erhält Permissions → auf Server waren dirs `drwxr--r--` (744).
- Webserver (www-data) braucht aber **Execute** auf Verzeichnissen → sonst 403 Forbidden.
- **Fix:** Nach rsync auf dem Server: `chmod -R u+rwX,go+rX ~/public/` (capital `X` = execute nur für dirs).
- Resultat: HTTP 200 auf allen Seiten.

### Working deploy command (Python, getestet)
```python
import os, subprocess
env = {}
with open('/root/.openclaw/workspace/projects/working-notes/.env') as f:
    for line in f:
        line = line.strip()
        if line and not line.startswith('#') and '=' in line:
            k, v = line.split('=', 1)
            env[k] = v
os.environ['SSHPASS'] = env['IONOS_PASSWORD']
subprocess.run([
    'rsync', '-avz', '--delete', '--info=progress2',
    '--chmod=Du=rwx,go=rx,Fu=rw,go=r',
    '-e', 'sshpass -e ssh -o StrictHostKeyChecking=accept-new',
    '/root/working-notes/_site/',
    f"{env['IONOS_USER']}@{env['IONOS_HOST']}:~/public/"
], check=True)
subprocess.run(['sshpass', '-e', 'ssh', '-o', 'StrictHostKeyChecking=accept-new',
                f"{env['IONOS_USER']}@{env['IONOS_HOST']}",
                'chmod -R u+rwX,go+rX ~/public/'], check=True)
```
